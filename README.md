# Humanity Mirror · 人类之镜

A unified bilingual model of civilization, consciousness, and decision — six interactive modules assembled into one cognitive infrastructure for the species that built them.

## Modules

1. **Civilization Timeline Engine** — Big Bang → 2026 → deep future, with structured science / events / impact per node
2. **Human Consciousness Model** — 12-node, 4-layer interactive graph (biology · cognition · society · meta)
3. **Global Decision Simulator** — type a scenario, get three branching futures (optimistic / realistic / dystopic) with probability, axis bars, ethical tradeoffs
4. **Humanity Metrics Dashboard** — 12 planetary indicators with sparklines + a long-arc trend chart (1930→2020)
5. **Civilization Strategy Engine** — 8 civilizational levers (UBI, Pause AI, Mars, Carbon War Footing, Longevity, Aligned AGI, Pro-natal, Planetary Governance) scored on 4 axes
6. **Knowledge Compression Layer** — same idea told three ways (Beginner / Expert / Philosopher) across 5 topics (Time, Consciousness, Civilization, Death, Truth)

## Features

- **Bilingual EN ↔ 中文** instant toggle (no reload), localStorage persisted
- **Cosmic dark-mode** aesthetic with starfield canvas
- **Live SVG graph** for consciousness with active-node edge highlighting
- **Procedural simulator** that generates plausible 3-path forecasts from any input
- **Embedded structured data** for all six modules (no backend required)

## Stack

Plain HTML + CSS + vanilla JS — single-file, zero build step, Vercel static hosting.
